CarioSpectra is a deep learning-based application designed to detect dental caries (tooth decay) from dental X-rays and intraoral images. It uses the YOLOv8 object detection model to identify potential caries regions and display bounding boxes with confidence scores.
The system includes image preprocessing, automated caries detection, severity assessment, and prediction history to help users understand the detection results. It aims to support early identification of dental caries through an accessible and user-friendly application.

Key Features
- Dental image upload and analysis
- Image preprocessing and enhancement
- YOLOv8-based caries detection
- Bounding boxes and confidence scores
- Caries severity assessment
- Prediction history and PDF reports

Technologies Used
- Frontend:React Native, Expo
- Backend: Python, FastAPI
- AI/Deep Learning: YOLOv8, Ultralytics
- Data Validation: Pydantic
CarioSpectra is an academic project developed to explore the use of artificial intelligence and deep learning in dental image analysis. It is intended as a supportive screening tool and does not replace professional dental diagnosis.
